Veterinaria App

Descripción
Sistema de gestión veterinaria desarrollado con Laravel. El proyecto tiene como objetivo facilitar la administración de los servicios y procesos de una veterinaria.

-Tecnologías utilizadas
Laravel
PHP
Composer

-Base de datos: veterinaria_app

-Funcionalidades
Gestión de información relacionada con la veterinaria.
Administración de los registros del sistema.

-Requisitos
PHP
Composer
Una base de datos compatible con la configuración del proyecto.

-Instalación
Clonar el repositorio.
Instalar las dependencias ejecutando composer install.
Copiar .env.example a .env.
Configurar las variables de entorno y la conexión a la base de datos.
Generar la clave de la aplicación ejecutando php artisan key:generate.
Ejecutar las migraciones si el proyecto las requiere, con php artisan migrate.

Ejecución
Iniciar el servidor de desarrollo con:

php artisan serve

Abrir en el navegador la dirección local que indique la terminal.
